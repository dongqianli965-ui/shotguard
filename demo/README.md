# Demo · 一键跑通示例

这个目录包含**真实的测试素材**，让你无需自己准备视频就能跑通 SHOTGUARD。

## 素材说明

三个视频用的是**同一个角色、同一个场景、同一个动作**，唯一差异是生成时用的提示词写法。

| 文件 | 提示词写法 | 字数 | 预期 |
|---|---|---|---|
| `case-a-naive-prompt.mp4` | 普通写法（随手写） | 18 | 崩坏最多 |
| `case-b-long-unstructured.mp4` | 等长非结构化（只堆气氛） | 568 | 模糊帧多 |
| `case-c-structured-prompt.mp4` | 结构化（含场景锚点/指纹锁） | 588 | 崩坏最少，但仍会检出 |
| `reference-character.png` | 三组共用的角色参考图 | — | — |

> 素材由灵镜（Lingjing）生成，480P / 5 秒 / 无音频。

## 一键跑通

### 1. 配置 API

```bash
export VISION_API_BASE_URL="https://api.openai.com/v1"
export VISION_API_KEY="sk-..."
export VISION_MODEL="gpt-4o"
```

> Windows PowerShell：
> ```powershell
> $env:VISION_API_BASE_URL="https://api.openai.com/v1"
> $env:VISION_API_KEY="sk-..."
> $env:VISION_MODEL="gpt-4o"
> ```

### 2. 跑验收

```bash
node ../src/shotguard-verify.js \
  case-a-naive-prompt.mp4 \
  reference-character.png \
  "17岁少女，黑色长直发及肩，右侧银色发夹，米色针织开衫内搭白衬衫，眼下有淡雀斑" \
  "木质地板，白色墙面，右侧一扇落地窗，窗下有灰色布艺沙发"
```

跑完会生成：
- `verify_report.json` — 结构化数据
- `verify_report.html` — 可直接给甲方看的报告（内嵌帧截图）

### 3. 跑另外两个案例做对比

把文件名换成 `case-b-long-unstructured.mp4` / `case-c-structured-prompt.mp4`，角色和场景描述不变。

## 三个案例用的原始提示词

### 案例 A · 普通写法（18 字）

```
一个女孩推门进入房间，然后看向窗边。
```

**预期结果**：崩坏最多——没有角色描述、没有场景约束、没有镜头控制。

---

### 案例 B · 等长非结构化（568 字）

```
一栋安静的公寓在午后。阳光透过客厅右侧那扇很大的落地窗斜斜地洒进来，空气里能看到细小的浮尘在光束中缓慢漂浮。少女站在门口，穿着一件薄薄的米色针织开衫，里面是白色衬衫。她留着黑色长直发，右侧别着一枚银色发夹，眼下有淡淡的雀斑。她的手扶着门把，把门推开。门轴发出轻微的声响。她向前迈了一步，脚步很轻，落在木质地板上几乎没有声音。房间很安静，只有远处街道上隐约传来的车流声。落地窗旁的灰色布艺沙发静静地摆在那里，白色的墙面在光里显得有些刺眼。她的头发在逆光里泛着柔和的光泽，发丝随着她走动的气流轻轻晃动。她停下了脚步，然后把头转向窗户的方向，视线落在窗外的某个地方。她的表情很平静，没有特别明显的情绪起伏，只是安静地看着。光在她的侧脸上留下一道淡淡的阴影。镜头缓缓记录着这一刻，画面安静而克制，色调温暖而不刺眼，构图平衡，景深很浅。整体氛围是那种午后特有的慵懒与平静，时间仿佛在这一刻慢了下来。地板的木纹在光里呈现出温润的质感，白色墙面反射着柔和的散射光。沙发旁边的矮几上放着一只玻璃杯，杯壁上有细密的水雾。窗外的树影在玻璃上投下摇曳的暗纹，随着微风轻轻晃动。
```

**关键**：字数与案例 C 相当（差 3%），但**没有**资产指纹锁、**没有**场景锚点声明、**没有**连续性禁令。

**预期结果**：模糊帧占比高——因为大段氛围描写让模型选择了虚化背景的构图，导致场景要素不可辨。

---

### 案例 C · 结构化（588 字）

```
电影级静态画面，写实电影感，高动态范围，柔和体积光，浅景深。

【人物材质】
17岁少女，黑色长直发及肩，右侧用银色发夹别起，米色针织开衫内搭白衬衫，眼下有淡雀斑，温和爱笑。皮肤质感细腻通透，表情克制靠微表情传达。

【灯光与风格】
主光源为右侧落地窗射入的午后自然光，自画面右方射入，色温约 5500K；阴影方向统一。

【核心特效】
仅保留与叙事相关的细节：发丝与衣料有自然质感与层次。

【参考资产映射】
@image1：少女的身份基准，只用于锁定外观，不得改变脸型五官与发型。

【资产指纹锁】
将@image1中的黑色长直发及肩、右侧银色发夹、米色针织开衫内搭白衬衫定义为<主体1>。全程沿用同一标签「主体1」，不得改写、不得增减特征。

空间布局与人物位置：少女位于画面左三分位，落地窗位于画面右侧。

【Continuity Block】
起始状态：少女手扶门把，站在门口，身体朝向画面右方。
光线状态：主光源自画面右侧射入，阴影投向画面左侧。

画面动作概述：少女推门进入房间，视线看向窗边
画面构图：中景，少女居左三分位，落地窗在画面右
镜头：平视视角
动作：推门，前进一步，视线右移

⚠️连续性禁令：必须严格遵循上述状态。禁止改变人物脸型五官、发型长度与分缝；禁止更换服装款式、颜色与穿着状态；禁止道具凭空出现或消失；禁止左右镜像翻转；禁止光影方向跳变。
```

**预期结果**：**崩坏最少，但仍会检出**。

这是整个项目的核心发现：**即使是最规范的结构化提示词，也无法 100% 防止崩坏。**

参考 [PersonaShot 论文](https://arxiv.org/abs/2608.16717) 的结论——跨镜头一致性相比单镜头，视觉质量衰减约 25%、情绪表达衰减约 50%：

> *"Even visually compelling videos frequently exhibit physical-state resets."*

## 注意事项

- **素材是真实 AI 生成内容**，仅供测试工具用
- 跑一次验收需要 6 次视觉模型调用（默认 6 帧），注意 API 配额
- 如果遇到 429 限流，工具会自动指数退避重试（2s → 4s → 8s）
- 中文角色/场景描述需带引号（因为含逗号）
