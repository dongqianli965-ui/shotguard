# SHOTGUARD · AI 视频自动验收工具 · 使用文档

> 版本：1.0
> 日期：2026-10-06
> 状态：已验证（3 条真实样本全部正确识别）

---

## 一、这是什么

**SHOTGUARD 是一个 AI 视频自动验收工具。**

你给它一段 AI 生成的视频 + 一张角色参考图 + 角色/场景描述，它自动检测 8 类崩坏（身份/服装/道具/空间/光线/状态/动作/声音），输出逐帧验收报告。

**核心价值：所有 AI 视频生成平台（可灵/即梦/Seedance/Runway 等）都把"一致性"做在输入侧（喂参考图），没有一家做"生成后自动验收"。SHOTGUARD 填补这个空白。**

---

## 二、为什么需要它

**真实案例（已验证）：**

| 样本 | 检测结果 | 说明 |
|---|---|---|
| **对照组 A**（普通写法 18 字） | 4 类崩坏（身份/道具/空间/光线） | 准确识别"灰色沙发缺失、出现不存在的床铺" |
| **对照组 B**（等长非结构化 568 字） | 模糊帧多，无法判断 | 符合 B 组"背景虚化"特征 |
| **实验组 C**（最好的结构化提示词 588 字） | 3 类崩坏（身份/道具/空间） | **证明连最好的提示词也不能 100% 防崩** |

**关键发现：连最好的结构化提示词也需要验收**——PersonaShot 论文（arXiv 2608.16717）早就说过"无法 100% 避免"。这正是验收工具的长期价值。

---

## 三、检测什么（8 类崩坏）

| 崩坏类型 | 说明 | 检测方法 |
|---|---|---|
| **身份漂移** | 人脸、发型、服装与参考图不一致 | 逐帧对比参考图 |
| **服装漂移** | 服装款式、颜色、穿着状态变化 | 逐帧对比参考图 |
| **道具漂移** | 道具凭空出现或消失 | 逐帧对比参考图 |
| **空间漂移** | 场景结构（门窗、家具、左右关系）变化 | 逐帧对比参考图 |
| **光线漂移** | 光源方向、阴影方向变化 | 逐帧对比参考图 |
| **状态回滚** | 天气、时间、破损等状态被无理由改变 | 逐帧对比参考图 |
| **动作断链** | 空镜（无人物）或动作不连贯 | 逐帧检测人物存在性 |
| **声音断链** | 声音空间、持续底噪不连贯 | 需音频分析，暂不支持 |

## 四、怎么用

### 方式 1：在线版（推荐，最简单）

1. 打开 `SHOTGUARD_验收工具_完整版.html`（双击即可，无需安装）
2. 填写 API 配置（OpenAI 兼容的视觉理解 API）
3. 上传视频 + 角色参考图
4. 填写角色/场景描述
5. 点击"开始验收"

**注意**：在线版是演示版（浏览器无法直接 ffmpeg 抽帧），完整功能请用 CLI 版本。

### 方式 2：CLI 版本（完整功能）

```bash
# 1. 设置环境变量
export VISION_API_BASE_URL="http://127.0.0.1:8787/v1"  # 你的 API 地址
export VISION_API_KEY="sk-..."                          # 你的 API Key
export VISION_MODEL="hy4-preview-f"                     # 你的模型名

# 2. 运行验收
node SHOTGUARD_verify.js "视频文件.mp4" "参考图.png" "角色描述" "场景描述"
```

**CLI 版本功能**：
- 自动抽帧（默认 6 帧，可配置）
- 逐帧视觉检测（8 类崩坏）
- 详细 JSON 报告（verify_report.json）
- 支持批量处理（循环调用）
- 置信度评分（成功检测帧数 / 总帧数）

### HTML 交付报告（新增）

工具现在同时生成两种报告：

1. **JSON 报告**（`verify_report.json`）—— 给程序/后续处理用
2. **HTML 交付报告**（`verify_report.html`）—— **直接给甲方看的销售物料**

HTML 报告特点：
- **单文件**（约 5MB），内嵌所有帧截图，不需要任何外部依赖
- 顶部明确状态（验收通过/未通过）
- 四个关键指标（置信度、总帧数、成功检测、崩坏帧）
- 参考图 + 角色/场景设定完整展示
- 崩坏统计（8 类崩坏各多少帧）
- 逐帧检测（每帧带截图 + 状态 + 问题列表）

**这就是可以直接发给客户的交付物**——客户打开就能看，不需要懂技术。

```
  帧 2/6 (1.44s) ... ✗ 空间漂移
  帧 3/6 (2.16s) ... ✗ 道具漂移、空间漂移
  帧 4/6 (2.88s) ... ✗ 身份漂移、道具漂移、空间漂移

  帧 6/6 (4.32s) ... ✓ 通过

无法判断：0
失败帧数：0

  身份漂移：1 帧
  道具漂移：2 帧
  空间漂移：3 帧

⚠️ 验收未通过
```

### 置信度说明

置信度 = 成功检测帧数 / 总帧数。

模型对模糊帧、背身帧可能无法判断，会标记为"无法判断"而不是误判。

**置信度 < 80% 时，建议：**
- 增加抽帧数量（提高覆盖率）
- 检查视频质量（是否过暗/过模糊）
- 检查参考图质量（是否清晰、正面）

## 八、已知限制

1. **声音断链不支持**：需要音频分析，当前只做视觉检测
2. **模糊帧无法判断**：模型对过暗/过模糊的帧会标记"无法判断"
3. **背身帧部分维度不可检测**：人脸不可见时，身份漂移只能依靠发型/服装判断
4. **需要视觉理解 API**：不支持纯图像生成 API（如 DALL-E、Midjourney）
