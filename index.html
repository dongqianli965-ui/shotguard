CLI 完整版（推荐）

在线版是演示（浏览器无法直接 ffmpeg 抽帧）。完整功能（抽帧 + 逐帧检测）请使用 CLI 版本。

# 1. 设置环境变量 export VISION_API_BASE_URL="https://api.openai.com/v1" export VISION_API_KEY="你的API密钥" export VISION_MODEL="gpt-4o" # 2. 运行验收 node SHOTGUARD_verify.js "视频文件.mp4" "参考图.png" "角色描述" "场景描述"

CLI 版本功能：

  • 自动抽帧（默认 6 帧，可配置）
  • 逐帧视觉检测（8 类崩坏）
  • 详细 JSON 报告（verify_report.json）
  • 支持批量处理（循环调用）
  • 置信度评分（成功检测帧数 / 总帧数）

使用说明

检测什么

崩坏类型说明
身份漂移人脸、发型、服装与参考图不一致
服装漂移服装款式、颜色、穿着状态变化
道具漂移道具凭空出现或消失
空间漂移场景结构（门窗、家具、左右关系）变化
光线漂移光源方向、阴影方向变化
状态回滚天气、时间、破损等状态被无理由改变
动作断链空镜（无人物）或动作不连贯
声音断链声音空间、持续底噪不连贯（需音频分析，暂不支持）

置信度说明

置信度 = 成功检测帧数 / 总帧数。模型对模糊帧、背身帧可能无法判断，会标记为"无法判断"而不是误判。
